# Эволюция Кода - Retro Landing Page

Лендинг закрытого клуба разработчиков в стиле пиксель-арта 80-90х годов.

Клуб объединяет 700+ разработчиков, которые хотят начать работать с ИИ и повысить свою продуктивность через использование AI-инструментов.

**Под разработчиками мы понимаем** всех людей с инженерным складом ума, которые пишут или хотят писать код с помощью ИИ: разработчики, инженеры, тестировщики, дизайнеры и другие специалисты.

## Запуск локально

Проект — чистая статика (HTML/CSS/JS), без сборки и зависимостей. Нужен любой статический HTTP-сервер:

```bash
# из корня репозитория
python3 -m http.server 8000
```

Затем открой [http://localhost:8000](http://localhost:8000) в браузере.

Альтернативы, если Python не установлен:

```bash
npx serve .        # Node.js
php -S localhost:8000   # PHP
```

Открывать `index.html` напрямую через `file://` не рекомендуется: часть браузерных ограничений (например, загрузка шрифтов и работа счётчика) ведёт себя иначе, чем на реальном хостинге.

**Деплой:** сайт хостится на GitHub Pages, домен настроен через файл `CNAME` (evocoders.ai). Любой пуш в ветку `main` автоматически публикует изменения.

## Особенности дизайна

### Цветовая палитра
- **Фиолетовый** (#9d4edd) - основной акцентный цвет
- **Синий** (#3c096c) - фоновый цвет
- **Циан** (#00f5d4) - неоновые подсветки
- **Зеленый** (#00ff41) - акценты
- **Темный** (#0a0e27, #050816) - базовый фон

### Технологии и эффекты
- **Conway's Game of Life** - анимированный фон
- **Share Tech Mono / Press Start 2P** - ретро-шрифты в стиле терминала
- **Pixel Art** стилистика с пиксельными границами
- **Neon Glow** эффекты для текста и элементов
- **Scanlines** эффект сканирующих линий
- **Glitch** анимации для усиления ретро-атмосферы

### Интерактивные элементы
- Плавные анимации при скролле
- Hover-эффекты с неоновым свечением
- Пульсирующие элементы
- Мигающие акценты
- Летающие частицы на фоне

## Структура
- `index.html` - основная страница (лендинг)
- `rules.html` - правила клуба
- `css/styles.css` - стили в pixel-art стиле
- `js/main.js` - Conway's Game of Life, карусели и интерактивность
- `js/archive.js` - данные и рендер архива контента (синхронизируются с базой знаний evocoders-learn)
- `js/battleCity*.js` - пасхалка: игра Battle City (запускается из футера)
- `robots.txt`, `sitemap.xml`, `llms.txt` - SEO/GEO-файлы
- `CNAME` - домен для GitHub Pages
- `tests/` - тесты (см. ниже); в прод не попадают

## Тесты

Прод остаётся чистой статикой: `package.json` и `node_modules` нужны только для тестов, на GitHub Pages они не выкладываются.

```bash
npm install   # один раз, единственная зависимость — jsdom
npm test
```

Тесты фиксируют текущее состояние лендинга и падают, когда данные разъезжаются между файлами.

| Файл | Что проверяет |
| --- | --- |
| `tests/archive-data.test.js` | Наполнение архива: количество записей по категориям, порядок вкладок, формат и сортировка дат, отсутствие дублей |
| `tests/content-sync.test.js` | Что статичная сводка архива и бейдж «последнее событие» в `index.html` совпадают с пересчитанными из `js/archive.js`; что цифры (700+, 450+, 200+, цены) одинаковы в разметке, JSON-LD и `llms.txt` |
| `tests/html-integrity.test.js` | Якоря, локальные файлы, id, которые ищет JS, счётчики каруселей, JSON-LD, мета-теги, `sitemap.xml`, `robots.txt`, `CNAME` |
| `tests/archive-render.test.js` | Поведение архива в DOM: переключение вкладок, группировка по годам, перерисовка списка |
| `tests/carousel.test.js` | Модалки и карусели: листание, границы, индикаторы, `Escape`, стрелки, свайпы, блокировка прокрутки |
| `tests/game-logic.test.js` | Правила Conway в фоне и инварианты Battle City: карты 13×13, по 20 танков на уровень, геометрия поля |
| `tests/learn-sync.test.js` | Что архив совпадает с навигатором контента в соседнем репозитории `evocoders-learn` |

### Сверка с базой знаний

`tests/learn-sync.test.js` ищет `../evocoders-learn` и **пропускается**, если репозитория нет рядом — прогон не ломается на чужой машине. Путь можно задать явно:

```bash
EVOCODERS_LEARN_PATH=/path/to/evocoders-learn npm test
EVOCODERS_LEARN_PATH=none npm test   # выключить сверку
```

Осознанные расхождения между лендингом и базой знаний перечислены в `ALLOWED_DIVERGENCE` внутри теста — с причиной для каждого. Если формулировки сойдутся, тест потребует убрать запись из списка, чтобы он не копил мусор.

### Когда тест упал

Почти всегда это значит, что цифру или запись поправили в одном месте и забыли в другом. Типичные случаи:

- **добавили контент в `js/archive.js`** - обнови статичную сводку и бейдж в `index.html` (их дублируют для краулеров без JS) и число записей в `llms.txt`;
- **сменили цену или размер сообщества** - поправь во всех местах сразу: hero, карточки, FAQ, JSON-LD, `llms.txt`;
- **добавили слайд в карусель** - добавь индикатор и поправь `.total-slides`.
